# Changelog

Notable changes to rst-auth are recorded here.

## Unreleased

- Added a standalone HTML/CSS/JavaScript documentation site and GitHub Pages deployment workflow.
- Added a browser-based auth flow demo to the Express example.
- Added a TypeScript Express API example that is installed from an npm pack tarball.
- Added usage, security, migration, contribution, reporting, and first-release documentation.
- Added Node 22/24 CI checks and example integration tests.

## 0.1.0 - 2026-10-16

- Initial alpha API for password hashing, access tokens, and opaque refresh-token rotation.
- Added Express 4/5 and Zod subpath adapters plus refresh-store conformance utilities.
